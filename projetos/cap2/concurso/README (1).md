# 📚 MATERIAL DE ESTUDOS: MACHINE LEARNING PARA CONCURSOS

## Sobre este Material

Este pacote de estudos foi criado especificamente para candidatos a concursos públicos que precisam dominar conceitos de Machine Learning. Todo o conteúdo foi baseado no notebook "02_end_to_end_machine_learning_project.ipynb" do livro "Hands-On Machine Learning" de Aurélien Géron, traduzido e adaptado para o contexto de preparação para concursos.

✅ Tratamento de valores ausentes

✅ Decision Trees

✅ Métricas (MSE, RMSE, MAE, R²)

✅ Intervalos de Confiança  

### Otimização
✅ Grid Search  
✅ Random Search  
✅ Análise de Hiperparâmetros  
✅ Feature Importance  

### Ferramentas
✅ Pandas (análise exploratória)
